# FPGA-Elevator-Controller
FPGA-based elevator controller implemented in Verilog HDL


FPGA Elevator Controller

Overview
- FPGA-based elevator control system
- Implemented in Verilog HDL
- FSM-based elevator control
- Stepper motor control
- Push-button input synchronization
- 7-segment display output
- 
Development Environment
- Board: Avnet Ultra96-V2
- Device Family: Xilinx Zynq UltraScale+ MPSoC
- Tool: Xilinx Vivado
- HDL: Verilog HDL
